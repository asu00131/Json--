# **App Name**: JSON Explorer

## Core Features:

- JSON Input: A text input area on the left side where the user can paste or type in a JSON string.
- JSON Tree View: Display the JSON in a tree-like structure on the left side for easy navigation and exploration, and enable search and focus by text input.
- JSON Path Preview: Display a read-only view of the value that corresponds to a JSON path input by the user. Provide buttons to copy the JSON path, and copy the current JSON preview result.

## Style Guidelines:

- Primary color: Light gray (#F5F5F5) for the background.
- Secondary color: White (#FFFFFF) for the input and display areas.
- Accent: Teal (#008080) for buttons and highlights.
- Split-screen layout with the JSON input/tree on the left and the path/preview on the right.
- Use a monospaced font for JSON data to improve readability.
- Use simple and clear icons for buttons (copy, expand/collapse tree nodes, etc.).
